greedy.guru

greedy записывает зелёный прогон Playwright-теста в JSON. Дальше этот файл гоняет Go-бинарник — напрямую в Chrome по CDP.

Ни Node, ни Playwright, ни модели в прогоне нет.

Что лежит в кристалле

Шаги и селекторы, снятые с трассы, а не разобранные из кода теста. Операций семь: navigate, wait, fill, click, text, park, eval — их хватает на логин, регистрацию и главную. park и eval пишутся руками: park оставляет вкладку на URL, eval — голый Runtime.evaluate; из трассы crystallize их не порождает.

{
  "id": "example",
  "kind": "cdp",
  "version": 1,
  "source": {
    "lang": "typescript-playwright",
    "fingerprint": "example-not-live"

  "steps": [
    { "op": "navigate", "url": "/login" },
    { "op": "wait", "selector": "[data-testid=login-username]", "timeout_ms": 5000 },

    { "op": "text", "selector": "[data-testid=home-welcome]", "value": "Welcome, user1!" },
    { "op": "park", "url": "/login" }
  ]
}

Пример из репо целиком — crystals/login.example.json. Живые кристаллы лежат рядом с тестами — tests-go-cdp.

Матрица: Mac против фермы

Тот же кристалл логина, но на живой SPA-странице. Слева — медиана серии, под ней лучший. Столбцы: очередь на одном Chrome и параллель на слотах пула.

Протокол: greedy bench — warmup и первый прогон клетки выбрасываются. Сырые прогоны — в bench-matrix.json.

Три контура запуска

1 · CI-мельница. Jenkins держит один слот пула через демон и гоняет login/logout/register/home; статусы кейсов уезжают в TestOps.

2 · Ферма напрямую. greedy bench/run лизит N слотов у пула — так замерена матрица выше (пять hot-cdp-миньонов на Box1).

3 · Локально. Один Chrome на ноуте против статичной страницы — так снят пин … выше.

Кто решает, что кристалл рабочий

Три зелёных прогона Playwright подряд — и кейс в TestOps просится на ревью. На ревью смотрят diff, дальше approve проставляет статус в TestOps и коммитит JSON. Без ревью в Live уезжает только логин (кейс 50707); поправили тест — кристалл возвращается на ревью.

greedy run --mode none \
  --cdp "$GREEDY_CDP" --base-url URL tests/go/tests-go-cdp/crystals/login.json

Рядом с run живут crystallize, validate, diff, approve и bench. CDP внутри свой и тонкий: ни chromedp, ни playwright-go.
